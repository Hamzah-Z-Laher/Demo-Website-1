# RSNT Accounting website

Static website for RSNT Accounting, Benoni: registered accountants, independent reviewers and tax consultants.

Plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser, or serve the folder with any static file server.

- `index.html`, `services.html`, `about.html`, `contact.html`: the four pages
- `css/style.css`: all styles
- `js/main.js`: navigation, scroll animations, service groups, service search and the contact form
- `assets/`: logo and favicon

The contact form opens the visitor's email app addressed to contact@rsnt.co.za; it does not send through a server.
